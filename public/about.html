About

Task Board is a tiny full-stack demo used to validate the Cloud Agent development environment. An Express server serves this static frontend and a small JSON API, while tasks live in an in-memory store that resets whenever the server restarts.

Head to the Board to add tasks, tick them off, and clear the completed ones.
